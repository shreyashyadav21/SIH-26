MineSafe (NMDC FogGuard) is an edge-optimized cyber-physical safety and fleet intelligence platform engineered to eliminate haul-road collisions and severe production halts in high-altitude open-cast mining environments, specifically targeting the NMDC Bailadila Iron Ore Complex in Chhattisgarh, India. Perched above 1,000 meters elevation, Bailadila experiences five months of intense monsoon cloud immersion (June to October) that drops atmospheric visibility to less than 3 to 5 meters. In these conditions, Heavy Earth Moving Machinery (HEMM)—such as 240-tonne haul dumpers—cannot visually identify road edges, obstacles, or preceding traffic, resulting in forced operational stoppages that directly threaten NMDC’s strategic roadmap to expand ore evacuation from ~53 MTPA to 100 MTPA by 2030.
MineSafe resolves this by combining client-side computer vision, procedural radar synthesis, Vehicle-to-Vehicle (V2V) spatial telemetry, and hands-free voice intelligence into an edge-ready, zero-cloud-dependent architecture deployable directly on in-cabin operator tablets and CCTV feeds.

At the core of the visual enhancement pipeline is a real-time, client-side dehazing engine implemented in video-analyzer.js and fog-model.js.
Rather than relying on high-latency cloud servers, the system executes pixel-level image processing directly in the browser using the HTML5 Canvas 2D API
It applies principles of the Dark Channel Prior (DCP) algorithm alongside statistical image feature extraction—calculating dynamic pixel luminance, RGB-channel dispersion, edge variance, and saturation metrics across raw video frames to classify fog density across four severity thresholds (Clear, Moderate, Dense, and Critical).
This is complemented by an integrated TensorFlow.js (COCO-SSD / MobileNet) inference engine that runs directly against incoming video streams to detect vehicles, obstacles, and terrain hazards, plotting real-time predictive bounding boxes
The user interface provides a dual-screen tactical view allowing operators to compare raw foggy camera feeds directly against the AI-cleared, contrast-stretched, dehazed feed with overlayed threat tags.

To supplement optical vision in complete whiteout conditions, the platform features a custom-engineered 360° tactical radar scope built inside radar-scope.js. Rendered using high-performance Canvas vector sweeps, the radar displays concentric metric range rings up to 100 meters, plotting our mining vehicle (DT-104) at the focal center while tracking peripheral dynamic hazards with threat vector indicators. To reduce visual cognitive load on operators navigating treacherous terrain, the system incorporates the Web Audio API to generate procedural, low-latency audio pings via software oscillators. As the radar sweep detects surrounding vehicles or roadside hazards within critical braking boundaries, the audio engine dynamically ramps chime frequency and ping repetition, giving drivers immediate acoustic distance feedback without taking their eyes off the road.

The platform’s command layer integrates a spatial fleet tracking and V2V proximity engine (fleet-tracker.js) powered by Leaflet.js and styled with CartoDB Dark Matter cartography. Simulating haul fleet movements (DMP-01 through DMP-10) across actual Bailadila mine sectors (Pit to Crusher, Crusher to ROM, and Hilltop Summit roads), the engine calculates real-time inter-vehicle Euclidean distance vectors. When vehicles enter unsafe stopping intervals during low-visibility conditions, proximity interrupts trigger instant visual alerts and control-room notifications. The central environment dashboard (environment.html) continuously ingests micro-climate data—including elevation, wind velocity, humidity, and calculated Fog Scores (0–100)—and visualizes live historical visibility degradation curves using Chart.js.


To ensure safety directives are instantly understood by operators in diverse regional workforces, MineSafe incorporates an acoustic modulation system (voice-alerts.js) built on the Web Speech API (SpeechSynthesis). The system dynamically modulates speech pitch (0.78x–1.18x), rate (0.78x–0.95x), and volume based on detected fog severity, issuing progressive voice advisories ranging from normal speed recommendations to mandatory emergency halts. Built with complete localization (i18n.js), all alerts and dashboard UI elements seamlessly switch across five Indian languages: English, Hindi (हिन्दी), Telugu (తెలుగు), Kannada (ಕನ್ನಡ), and Tamil (தமிழ்). Furthermore, recognizing that dumper drivers wearing industrial gloves cannot interact with touchscreens, voice-assistant.js deploys continuous Web Speech Recognition (webkitSpeechRecognition), enabling completely hands-free screen switching and system queries through spoken vocal triggers (e.g., "Radar", "Environment", "Video", "Training", "Home").


To support continuous edge improvement, the repository includes training architectures and parameter optimization scripts. In training.html and train_visibility.py, the training pipeline documents and simulates YOLOv8 and EfficientNet architectures benchmarked against the RESIDE (Realistic Single Image Dehazing) and FRIDA (Foggy Road Image Database) datasets with mine-specific contrast augmentation. Additionally, the project features an autonomous LLM optimization bridge (ollama_trainer.py) that interfaces via local REST API with Ollama running the llama3.2:3b model. The script queries the local vision core with scene descriptors, programmatically receives optimal contrast, brightness, and saturation factors, and automatically injects these tuned weights directly into the active JavaScript dehazing engine—creating an adaptive, self-tuning edge enhancement loop.


* **User Interface & Styling:** HTML5, CSS3 Grid/Flexbox, Custom Cyberpunk HUD / Glassmorphism Design System, CSS Keyframe Animations.
* **Computer Vision & Video Processing:** HTML5 Canvas API, Dark Channel Prior (DCP), Dynamic Histogram & Contrast Stretching, TensorFlow.js (COCO-SSD / MobileNet).
* **Radar & Spatial Acoustics:** HTML5 2D Canvas vector rendering, Web Audio API (procedural sine/square oscillator chimes).
* **Geospatial & Telemetry:** Leaflet.js, OpenStreetMap CartoDB Tiles, Chart.js (Real-time line & area charts).
* **Voice Intelligence:** Web Speech API (`SpeechSynthesis` & `SpeechRecognition`), Localized Translation Engine (English, Hindi, Telugu, Kannada, Tamil).
* **Local Server & AI Optimization:** Python 3 (`http.server` with cache-control headers), Ollama API (`llama3.2:3b`), NumPy & simulated deep contrast training pipelines.
